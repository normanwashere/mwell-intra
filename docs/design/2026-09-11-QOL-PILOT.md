## Changes and use

- My Work remembers the current view and scroll position when opening a record and returning. Existing URL search/filter handling remains in use.
- Procurement PO rows carry validated status-filter and sort context into detail. Back to POs restores that context. Scroll checkpoints are per user and tab, expire after 30 minutes, and store numeric offsets, not records or search text.
- PO and fulfillment order detail have Copy reference and Copy record link icon buttons. The link is canonical, same-origin and free of access tokens or customer details. The recipient must still sign in and have access. Clipboard rejection produces an honest failure message.
- Existing pinned order-sheet footers and desktop request-wizard actions were retained. Footer groups now have accessible names. No duplicate submit buttons were introduced.
- The request wizard warns on browser exit and its explicit Cancel action if user edits or pending attachments are not saved. Cancelling the warning retains the form; reverting edits removes the warning. Existing autosave remains unchanged.
- Order intake prompts before closing when local draft storage failed to save an edit. Existing in-flight submission locking and durable recovery are unchanged.

## Workflow boundaries

No database schema, access rule, approval threshold, validation rule, or transaction handler was changed. The convenience controls do not submit forms. Browser capture blocked operational writes. Existing happy/negative submission, draft recovery, and duplicate-submit component tests were rerun.

This is a scoped first batch. Exit warnings are not yet a universal guard for SPA browser Back, arbitrary programmatic navigation, every form, or every role. No router/history interception was introduced to pretend otherwise. Durable draft storage was not extended to new sensitive fields. Published KB/manual screenshots remain aligned to live UAT until promotion; this document describes the candidate only.
